# 变更：考勤历史页面支持员工姓名搜索

## 原因
当前考勤历史页面仅支持按员工工号搜索，当用户忘记员工工号但记得姓名时，无法快速找到相关记录，降低了系统易用性和查询效率。

## 变更内容
- 在考勤历史页面搜索表单中添加员工姓名输入框
- 修改后端服务逻辑，支持按员工姓名查询考勤历史记录
- 保持现有员工工号搜索功能，两种搜索方式可单独或组合使用
- 更新前端查询逻辑，处理姓名和工号的组合搜索条件

## 影响
- **受影响的规范**：考勤管理
- **受影响的代码**：
    - `views/attendance_history_manage.html`: 添加员工姓名搜索输入框和修改前端查询逻辑
    - `service/attend_record.go`: 修改`GetAttendRecordHistoryByStaffId`函数，支持按姓名查询
    - `handler/attend.go`: 可能需要修改处理函数以支持新的查询参数
