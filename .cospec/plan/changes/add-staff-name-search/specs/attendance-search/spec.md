## ADDED Requirements
### Requirement: 考勤历史页面员工姓名搜索功能
系统应在考勤历史页面提供按员工姓名搜索的功能，使用户能够通过员工姓名快速查找考勤历史记录。

#### Scenario: 成功使用员工姓名搜索
- **WHEN** 用户在考勤历史页面输入员工姓名并点击搜索
- **THEN** 系统返回匹配该员工姓名的所有考勤历史记录

#### Scenario: 员工姓名和工号组合搜索
- **WHEN** 用户同时输入员工姓名和工号并点击搜索
- **THEN** 系统返回同时匹配姓名和工号的考勤历史记录

## MODIFIED Requirements
### Requirement: 考勤历史查询功能
考勤历史查询功能应支持多种查询条件组合，包括员工工号和员工姓名，提高查询灵活性。

#### Scenario: 使用现有工号搜索功能
- **WHEN** 用户仅输入员工工号并点击搜索
- **THEN** 系统返回匹配该工号的所有考勤历史记录（保持原有功能不变）

#### Scenario: 不输入任何搜索条件
- **WHEN** 用户不输入任何搜索条件直接显示页面
- **THEN** 系统返回所有考勤历史记录（保持原有功能不变）
