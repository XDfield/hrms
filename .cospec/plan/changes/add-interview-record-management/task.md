## 1. 目标
创建一个集中的面试记录管理页面，提供全面的面试记录查看、筛选、编辑和统计功能，方便HR和管理人员高效管理所有面试记录。

## 2. 实施
- [ ] 2.1 前端：创建 `views/interview_record_manage.html` 页面，实现面试记录列表展示、筛选、编辑和删除功能。
- [ ] 2.2 前端：创建 `views/admin_interview_record_manage.html` 页面，为管理员提供更高级的面试记录管理功能。
- [ ] 2.3 后端：在 `main.go` 中添加面试记录管理页面的路由配置。
- [ ] 2.4 后端：添加面试记录管理的API处理函数（如 `GetInterviewRecords`），支持分页、筛选和排序。
- [ ] 2.5 配置：在 `static/api/menus.json` 中添加面试记录管理菜单项，包括普通用户和管理员两个入口。
- [ ] 2.6 前端：实现面试记录的创建和编辑表单，包括基本信息和评分评价区域。
- [ ] 2.7 前端：实现面试记录的批量操作功能，包括批量选择和批量删除。
- [ ] 2.8 前端：实现面试记录统计功能，展示面试数据的统计图表和分析结果。
- [ ] 2.9 前端：实现面试记录导出功能，支持将筛选后的数据导出为Excel文件。
- [ ] 2.10 前端：优化面试记录详情查看功能，提供完整的面试信息展示。
