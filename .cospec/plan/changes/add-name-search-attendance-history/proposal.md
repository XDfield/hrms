# 变更：考勤历史页面添加姓名搜索功能

## 原因
当前考勤历史页面只支持通过员工工号进行搜索，但用户可能只知道员工姓名而不知道工号，导致查询不便。添加姓名搜索功能可以提高系统的可用性和用户体验。

## 变更内容
- 在考勤历史页面的搜索表单中添加姓名搜索输入框
- 修改后端API，支持通过员工姓名查询考勤历史记录
- 保持现有的工号搜索功能不变
- **BREAKING**: 无破坏性变更，仅新增功能

## 影响
- **受影响的规范**：考勤查询功能
- **受影响的代码**：
    - `views/attendance_history_manage.html`: 添加姓名搜索输入框和修改搜索逻辑
    - `handler/attend.go`: 修改处理考勤历史查询的函数
    - `service/attend_record.go`: 添加支持姓名搜索的查询方法
    - `main.go`: 可能需要添加新的路由处理姓名搜索
