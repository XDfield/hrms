## ADDED Requirements

### Requirement: 考勤历史姓名搜索
系统应提供通过员工姓名搜索考勤历史记录的功能。

#### Scenario: 通过姓名成功搜索考勤历史
- **WHEN** 用户在考勤历史页面输入员工姓名并点击搜索
- **THEN** 系统显示匹配该员工姓名的所有考勤历史记录

#### Scenario: 同时输入工号和姓名进行搜索
- **WHEN** 用户同时输入工号和姓名进行搜索
- **THEN** 系统优先使用工号进行查询，忽略姓名输入

#### Scenario: 输入不存在的姓名进行搜索
- **WHEN** 用户输入不存在的员工姓名进行搜索
- **THEN** 系统显示"没有找到匹配的记录"提示

#### Scenario: 多个员工具有相同姓名
- **WHEN** 多个员工具有相同的姓名
- **THEN** 系统显示所有匹配该姓名的员工的考勤历史记录

## MODIFIED Requirements

### Requirement: 考勤历史查询
系统应支持通过员工工号或姓名查询考勤历史记录。

#### Scenario: 通过工号查询考勤历史
- **WHEN** 用户在考勤历史页面输入员工工号并点击搜索
- **THEN** 系统显示该员工的考勤历史记录

#### Scenario: 不输入任何条件查询
- **WHEN** 用户不输入任何搜索条件直接点击搜索
- **THEN** 系统显示所有考勤历史记录
